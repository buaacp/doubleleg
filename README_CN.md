# 模块化关节机械腿 R1

本版从零建模，不继承 V12/V13 的曲面杆件。所有自制腿体零件限定为等宽平板、矩形减重窗、圆孔、圆轴和隔套，便于水切割/激光切割后钻铰加工。

轴距与当前仿真冻结值一致：髋轴到膝轴 158.1708 mm，膝轴到踝轴 163.5926 mm。每段双片杆件仅保留一根空心铝隔套和一根 M4 贯穿螺栓，安装在减重窗下方的实体腹板区。左右侧板均有 M4.3 通孔，不允许横撑轴线落入镂空区。

## 正确的关节连接

FR12-H103GM 本质上是 X430 系列的铰链框架，不是电机。正确的双侧支撑顺序是：

1. 舵机壳体固定在上游构件；
2. 舵机输出盘通过 M2 螺钉连接 U 形框驱动侧板；
3. 舵机背面安装同轴惰轮盘/轴承，连接另一侧延伸模块；
4. 左右延伸模块从关节轴向腿部方向伸出，并由远端桥板保持间距；
5. 下游双片腿杆只在延伸模块远端双孔处连接，每侧两颗 M4；
6. 腿板不接触、不夹持电机壳体；电机扭矩经输出盘、延伸模块再传给腿板。

## 生产前必须替换的参数

`config.json` 中的 X430 尺寸只用于表达安装拓扑和包络。X430 级关节的堵转扭矩约 4.1 N·m，不能直接替代当前 12 N·m 峰值目标。确定最终大扭矩模块后，需要用厂商 STEP 核对并替换：机身包络、输出盘孔距、惰轮接口、U 框净宽和线缆出口。

## 生成

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python build.py
```

生成 `output/` 下的完整腿、关节装配、爆炸图、STEP、BOM 和校核记录。
脚本使用仓库内 `vendor/v5_foot_parts/` 的 V5 足爪 STEP，不依赖原工作区。

全腿的零件编号、螺栓规格、扭矩、防松方式和装配顺序见 `全腿装配与连接规范_R2.md`；可机器读的连接表和工程 BOM 分别为 `connection_matrix.csv` 和 `engineering_BOM.csv`。
